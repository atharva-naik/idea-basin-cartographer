3EMBED · LSA + triplets + t-STE

Low-rank topic similarity → “i closer to j than k” constraints → t-distributed STE map.
How it works
1. TF-IDF over title ×2 + abstract + keywords ×2 + spec body.
2. Truncated SVD (LSA) → smooth topic-space cosine; ranks near-orthogonal sparse vectors into a few idea families.
3. Triplets: sample j from top-N neighbours, k from the least similar half, keeping only confident margins.
4. t-STE minimises −log ψ(a)/(ψ(a)+ψ(b)), ψ(t)=1/(1+t) (Student-t, ν=1). Closed-form gradient, AdaGrad + momentum, PCA/MDS init, best-of-restarts.
5. k-means basins named by dominant topic; KDE contours, convex hulls, kNN sparsity frontier, low-density cells between ≥2 basins = coverage gaps.
